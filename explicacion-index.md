# Explicacion del header y sus etiquetas


1. Las Fundamentales (El Esqueleto)
<html>: El contenedor raíz que envuelve toda la página.

<head>: El cerebro con la información invisible (configuraciones, títulos de pestaña).

<body>: El cuerpo visible donde va todo el contenido que ve el usuario.

2. Estructura y Semántica (El Plano de la Casa)
<header>: La parte superior o encabezado.

<nav>: La zona de menús y navegación.

<main>: El contenido principal y más importante de la página.

<section>: Una sección temático dentro del contenido.

<article>: Un bloque de contenido independiente (como una noticia o post).

<aside>: Una barra lateral para contenido secundario o publicidad.

<footer>: El pie de página o zona inferior.

<div>: Una caja genérica e invisible para agrupar lo que sea cuando no hay una etiqueta específica.

3. Textos y Títulos (El Contenido Escrito)
<h1> al <h6>: Encabezados y títulos (del más grande al más pequeño).

<p>: Párrafos de texto.

<span>: Un pedacito de texto dentro de una línea para aplicarle estilos o cambios específicos.

<strong>: Pone el texto en negrita y le da importancia.

<em>: Pone el texto en cursiva o le da énfasis.

<blockquote>: Para citas o frases textuales largas.

4. Enlaces y Multimedia (La Interacción y la Vista)
<a>: Enlaces para viajar a otras páginas o secciones.

<img>: Para insertar imágenes.

<audio>: Reproductor de sonido o música.

<video>: Reproductor de videos.

<iframe>: Una ventana para incrustar otra página web (como un video de YouTube).

5. Listas (El Orden)
<ul>: Lista desordenada (con viñetas/puntos).

<ol>: Lista ordenada (con números 1, 2, 3...).

<li>: Cada elemento individual dentro de una lista.

6. Formularios y Datos (La Entrada de Información)
<form>: La caja del formulario completo.

<input>: Campos para escribir datos (texto, contraseña, correo, casillas de verificación).

<textarea>: Una caja de texto grande para mensajes largos.

<button>: Botón donde se puede hacer clic para enviar o activar una acción.

<select> y <option>: Menú desplegable para elegir una opción de una lista.

<label>: El texto explicativo al lado de un campo de texto.

7. Tablas (Datos Organizados)
<table>: La tabla en sí.

<tr>: Una fila de la tabla.

<td>: Una celda de datos.

<th>: Encabezado de una columna.
